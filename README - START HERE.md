├── index.html
├── pages/
│   ├── work.html

    ├── js/
    │   └── main.js
    └── images/

        └── projects/

Only `index.html` is kept in the root.
All other website pages are inside `pages/`.

## CSS
Main stylesheet:
`assets/css/style.css`

## JavaScript
Main JavaScript:
`assets/js/main.js`

## Run
Open the complete `RENOBVA_Website` folder in VS Code.
Then right-click `index.html` and choose **Open with Live Server**.
