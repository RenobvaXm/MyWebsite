# Guided client brief

Replace your website files with this version and restart Node, or publish the updated public folder to your hosting.

Contact and New Project now share a four-step brief: essentials, tailored questions and features, optional assets, then review. Signed-out clients return to the review step after login. Details and selected files are saved in this browser for 24 hours using IndexedDB; moving to another device does not transfer the draft.

Assets: up to 10 supported files, 15 MB per file. These upload to the existing private project-files bucket and appear in the conversation and Admin Dashboard → View brief. Use Download for an individual file or Download all ZIP for a project folder. Downloads use the browser’s configured download location. Brief assets are grouped in an expandable Project files panel instead of large chat previews. ZIP downloads have a 250 MB browser-memory limit. No database setup or new keys are required.

If an upload fails after the project is created, retry Send to upload the remaining files without creating another project, or open the saved project from the portal. Email behavior and Stripe configuration use your existing setup.
